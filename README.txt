SISTEMA RUPE 100% - REGISTRO ÚNICO DE PERROS EXTRAVIADOS

Descripción:
RUPE es un sistema web desarrollado con Java 17, Spring Boot, Thymeleaf y MySQL.
Permite registrar perros extraviados, generar folio único, consultar por folio,
registrar pistas, subir fotografías, generar QR, generar ficha PDF, exportar reportes,
ver gráficas, administrar usuarios, consultar bitácora, controlar intentos de login
y crear respaldos informativos.

Correcciones incluidas:
1. El campo color ya no acepta números.
2. El campo color ya no permite guardarse vacío.
3. El campo señas particulares ya no acepta números ni signos.
4. El campo señas particulares ya no permite guardarse vacío.
5. La fecha de extravío ya no permite años con uno, dos o tres dígitos.
6. La fecha de extravío ya no permite campo vacío.
7. Se valida fecha en frontend y backend.
8. Se agregan pistas, fotos_reportes, fichas_pdf, configuracion_sistema, intentos_login y respaldos.
9. Se agregan funciones avanzadas: fotografía, QR, pistas, PDF, CSV, gráficas, pruebas automatizadas y seguridad de contraseña.
10. Se agrega límite de intentos de login.
