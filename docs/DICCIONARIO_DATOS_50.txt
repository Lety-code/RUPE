DICCIONARIO DE DATOS DEL 50%

Tabla: roles
Campos: id, nombre, descripcion, activo.
Uso: Guarda los roles administrativos.

Tabla: usuarios
Campos: id, nombre, correo, password, activo, rol_id.
Uso: Guarda usuarios que pueden entrar al panel.

Tabla: tutores
Campos: id, nombre, telefono, correo, direccion, fecha_registro.
Uso: Guarda datos del responsable del perro.

Tabla: perros
Campos: id, nombre, raza, color, tamano, sexo, senas_particulares, foto_ruta.
Uso: Guarda datos del perro extraviado.

Tabla: reportes_extravio
Campos: id, folio, tutor_id, perro_id, fecha_extravio, lugar_extravio, descripcion, estado, fecha_registro.
Uso: Guarda el reporte principal de extravío.

Tabla: bitacora
Campos: id, usuario, modulo, accion, ip, fecha_hora.
Uso: Guarda acciones importantes del sistema.
